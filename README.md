# Treino Matred

Aplicativo pessoal de hipertrofia com cinco treinos semanais, cronometro de descanso, registro de series, cargas e repeticoes, exemplos de execucao e funcionamento offline.

## Publicar no GitHub Pages

1. Abra **Settings > Pages** no repositorio.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch **main** e a pasta **/(root)**.
4. Clique em **Save**.

O endereco sera: https://matredamandio.github.io/Treino/

## Dados

Os registros ficam somente no armazenamento local do navegador. Use a opcao de exportacao no aplicativo para fazer backup.
